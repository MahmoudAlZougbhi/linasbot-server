IMPLEMENTATION-READY MOBILE UI


Linas AI - Screen-by-Screen Design Handoff
One implementation page per approved mobile screen, with light/dark designs, control behavior, route ownership, backend dependencies, and acceptance
checks.

             8 approved screens                 2 theme variants                    1 physical-left drawer                              10 guest prompts
                                                                                         BINDING PRODUCT DECISION
                                                                                             •   Chat opens first. Guests can complete 10 server-accepted prompts; unique
                                                                                                 attempt 11 is gated before send and resumes after authentication.
                                                                                             •   Linas controls the AI that answers Facebook/Instagram DMs and
                                                                                                 comments. There is no post, Story, Reel, video, generated-media,
                                                                                                 scheduling, queue, or publishing workflow.
                                                                                             •   One physical-left drawer contains all modules and chat history. There are
                                                                                                 no bottom tabs or right-side navigation.
                                                                                             •   Mobile and web use the same canonical authentication, tenant/RBAC,
                                                                                                 configuration, Meta, conversation, billing, usage, and settings services.
                                                                                             •   The star is the only assistant brand object. No mascot, face, robot avatar,
                                                                                                 or copied OpenAI/ChatGPT identity asset is permitted.

                                                                                             Cursor implementation rule: Treat each following page as the visual
                                                                                             contract for that representative screen. The full 83-screen registry and 530-
                                                                                             control matrix in the master specification remain the normative route and
                                                                                             edge-state source of truth.

                                                                                         AI EXECUTION
                                                                                         Keep provider keys and model names in a server-side registry. Select the strongest
                                                                                         evaluated model per task, and require typed deterministic tools plus dedicated
                                                                                         review/confirmation for every protected mutation.
