# Linas AI — Landing Page Design Package

هذا الملف يجمع التصميم المرئي الكامل للـLanding Page مع صور شاشات تطبيق Linas AI والـBrand assets.

## رابط المعاينة المباشرة

https://linas-ai-landing.mahmoudalzougbhi637.chatgpt.site

## محتويات الباكج

- `LINAS_AI_LANDING_PAGE_DESIGN_OVERVIEW.jpg`: نظرة واحدة على أقسام الصفحة كلها.
- `01_LANDING_PAGE_SCREENSHOTS/`: تسع صور واضحة للـHero، Features، How it works، App tour، Pricing، Resources، Download، Contact، وGuest AI.
- `02_APP_DESIGN_SCREENS/`: صور شاشات التطبيق المستخدمة داخل التصميم: Guest Chat، Owner Copilot، Navigation، Content Management، Integrations، Live Chat Audit، وSettings.
- `03_BRAND_ASSETS/`: شعار Linas AI وأيقونة التطبيق بصيغة SVG.

## التوجه المعتمد

- المنتج مخصص للرد بالـAI على Facebook وInstagram DMs وcomments فقط.
- لا يوجد إنشاء Posts أو Stories أو Reels أو Videos.
- الدخول الأساسي Chat-first، مع 10 guest prompts قبل طلب تسجيل الدخول.
- Live Chat مخصص للعرض والتدقيق فقط، وليس للرد اليدوي.
- الأسعار الحقيقية وروابط App Store وGoogle Play يجب أن تأتي من المصادر الرسمية عند ربطها بالإنتاج.
